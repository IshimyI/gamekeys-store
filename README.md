# GameKeys Store — тестовое задание

Магазин цифровых товаров для геймеров: ключи, пополнения, подписки, гифт-карты.
Главный фокус — товар выдаётся ровно один раз, даже под нагрузкой.

## Как запустить

Нужен Node.js 22.5+ (используется встроенный `node:sqlite`, ничего собирать не надо).

```bash
cd server
npm install
npm run seed      # создаёт server/data.sqlite, добавляет товары, ключи, промокоды
npm start         # http://localhost:3000
```

Откройте `http://localhost:3000`. Перед покупкой можно ввести промокод:
`WELCOME10` (-10%, лимит 100), `GG500` (-500₽, лимит 20), `LIMIT3` (-25%, лимит 3),
`ONCEONLY` (-50%, лимит 1).

## Как проверить гонки

```bash
cd server
npm run load-test   # сервер должен быть уже запущен (npm start в другом терминале)
```

Скрипт `scripts/load-test.js` прогоняет все сценарии из критериев: 50 параллельных
вебхуков с одним event_id и с разными, вебхук раньше заказа, пустой склад с
довыдачей, промокод с лимитом под параллельной нагрузкой.

## Как устроена однократная выдача

Коротко — в `NOTES.md`, раздел «Однократная выдача».

## Что сделано по этапам

- **Этап 1** — витрина по макету, покупка, вебхук-заглушка оплаты, автовыдача ключа.
- **Этап 2** — однократная выдача под конкурентными вебхуками.
- **Этап 3** — что делать, если ключей нет: заказ уходит в `out_of_stock`/
  `delivery_failed`, `GET /api/admin/undelivered-orders` — список таких заказов,
  `POST /api/admin/orders/:id/retry` — повторная выдача, `POST /api/admin/restock`
  — пополнить склад.
- **Этап 4** — промокоды с лимитом, скидку всегда считает сервер.

## Что не делал специально

Эквайринг, авторизацию, отзывы, тёмную тему, пиксель-перфект, дизайн админки —
как и написано в задании, что не нужно. А вот каталог и футер сделал подробнее,
чем требовалось (по условию для каталога хватило бы просто открытия/закрытия).
